# Лендинг «ОГЭ на 5»

Одностраничный лендинг для Сайфуллиной Олеси Раифовны. Основное целевое действие — звонок по номеру `+7 960 383-78-57`, дополнительное — сообщение в MAX.

## Просмотр

```powershell
python -m http.server 8000 -d oge-five-landing
```

Затем открыть `http://localhost:8000`.

## Важно перед публикацией

SEO-файлы `robots.txt`, `sitemap.xml` и canonical в `index.html` подготовлены под домен `oge-na-5.ru`. Если будет выбран другой домен, нужно заменить его в этих трёх местах.

Заявленные результаты и кейсы основаны на информации преподавателя. Перед публикацией стоит хранить подтверждения результатов отдельно; персональные данные учеников на сайте не раскрываются.

Формулировка об итоговой отметке описывает действующий принцип математического округления средней годовой и экзаменационной отметок. При изменении нормативных правил текст следует актуализировать.
