# Тренажёр задания №10: спецификация

## Цель

Добавить в первую часть математического тренажёра полное задание №10 по той же визуальной и функциональной модели, которая уже работает для заданий №6–9.

## Источник и объём

- источник: актуальный раздел MathStart / FIPI_OGE_MATH / probabilities;
- 18 прототипов;
- полный замкнутый набор из 217 уникальных заданий;
- распределение: 10, 16, 16, 16, 8, 17, 10, 16, 10, 6, 10, 16, 16, 10, 10, 10, 10, 10.

## Интерфейс

- отдельная страница `task10.html` в существующем стиле тренажёров;
- слева сохраняется компактная навигация 1–19 и ссылка «Мой прогресс»;
- сверху внутри задания — 18 переключателей прототипов;
- у каждого задания поле ответа;
- Enter сразу проверяет конкретный ответ и окрашивает карточку;
- зелёный — верно, жёлтый — отвечено неверно, розовый — ещё не решено;
- ответы разных прототипов не смешиваются.

## Прогресс

- локальное сохранение изолировано ключами задания №10;
- при авторизованном ученике состояние синхронизируется с `trainer_progress.math.task10`;
- общая диаграмма кабинета получает цветовой стек и процент для столбца №10;
- процент равен доле правильных ответов от всех 217 заданий.

## Приёмка

- отображаются 18 прототипов и 217 уникальных заданий;
- русская кодировка не повреждена;
- проверка по Enter работает;
- переключение прототипов не переносит ответы;
- после возврата ответ сохраняется;
- прогресс №10 отображается в кабинете;
- существующие задания №6–9 продолжают работать.
