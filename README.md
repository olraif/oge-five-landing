# ОГЭ на 5 — тренажёр

Домен https://oge-na-5.ru/ предназначен для тренажёра. Корневая страница сразу переводит посетителя в кабинет https://oge-na-5.ru/study/. Действующие ссылки на задания, вход, регистрацию и прогресс остаются в разделе study/.

Лендинг Олеси Сайфуллиной для индивидуальных занятий подготовлен отдельно в репозитории RepIQ, в папке oge/. Его адрес после публикации: https://repiq.ru/oge/. Ссылки «Заказать индивидуальный урок» в математическом и информатическом кабинетах ведут туда.

## Локальная проверка

Из корня репозитория запустите: python -m http.server 8000

Затем откройте http://localhost:8000/ и убедитесь, что браузер перешёл на /study/. Полный набор проверок: python -m unittest discover -s tests -v

## Порядок публикации

Сначала опубликовать страницу https://repiq.ru/oge/ и проверить её изображения и ссылку на кабинет. Затем публиковать этот репозиторий на oge-na-5.ru. Не переключать корневую страницу раньше, чем заработает страница записи на RepIQ.

Перед передачей всего тренажёра новому владельцу отдельно обновить оператора персональных данных, документы, оплату и администрирование базы учеников. До этого момента действующие документы и платёжные настройки не изменяются автоматически.
