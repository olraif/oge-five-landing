# Задание 6: сгруппированный прогресс

## Цель

Связать тренажёр задания № 6 с общей диаграммой кабинета ученика без усредняющего порога «5 правильных». Общая диаграмма должна переносить фактические состояния всех аналогов 6.1–6.10.

## Согласованная логика

- Каждый введённый и правильный ответ — зелёная ячейка.
- Каждый введённый, но неправильный ответ — жёлтая ячейка.
- Каждый аналог без ответа — бледно-розовая ячейка.
- Внутри каждого прототипа цвета группируются: зелёные снизу, жёлтые выше, розовые сверху.
- Прототип становится полностью зелёным только тогда, когда правильны все его аналоги.
- Столбик задания № 6 состоит из десяти отдельных участков 6.1–6.10 и сохраняет границы между ними.
- Под номером задания показывается только процент: количество зелёных аналогов задания № 6, делённое на общее количество его аналогов.
- Для текущего набора общее количество аналогов равно 85: восемь прототипов по 9, затем 6.9 — 6 и 6.10 — 7.

## Источник данных

Единственный источник состояния — `user.user_metadata.trainer_progress.math.task6` в Supabase. Для совместимости с уже сохранёнными попытками количество правильных берётся из `score`, количество отвеченных — из непустых значений `answers`, общее количество — из `total`, длины `answers` или таблицы ожидаемых размеров прототипов.

## Отображение

Основной экран прогресса не сообщает «освоен/не освоен». Он показывает только цветовую структуру и процент. Подробности конкретных ошибок остаются внутри тренажёра.
